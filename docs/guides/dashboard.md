# 首页数据驾驶舱

后台首页用于了解博客访问变化、比较文章表现、查看相册与处理日常待办。界面沿用浅灰白背景、靛蓝主色和现有侧边导航，默认展示近 30 天，可切换近 7 天和近 90 天。

## 页面内容

| 区域 | 展示与操作 |
| --- | --- |
| 顶部工具栏 | 统计日期、数据更新时间、区间选择、刷新和新建文章 |
| 核心指标 | 今日站点访问、区间站点访问、区间文章访问、区间相册访问、区间新增评论及当前待审核评论 |
| 访问趋势 | 站点与已发布文章的每日计数，按日期补齐零值 |
| 内容状态 | 已发布、草稿、私有、归档文章及相册、照片数量 |
| 文章排行 | 区间访问排序的五篇已发布文章，带封面、标签和累计计数 |
| 运营待办 | 待审核评论、最近草稿及已发布文章缺封面提示，提供管理入口 |
| 相册一览 | 最多四个相册，含封面、状态、照片数量和区间访问 |
| 近期内容 | 最近更新的五篇文章摘要，私有状态明确标注 |
| 资源概况 | 有效资源数量、图片数量、资源登记大小及最近公开图片预览 |

文章和相册图片来自已保存的内容地址；缺图或图片加载失败时保留占位、标题与管理入口。首页不申请文件下载签名，不触发下载审计。

## 统计口径

- 统计日期以数据库当前日期为准，区间含今天，不包含未来日期。
- 访问计数经过每日按 IP 哈希、事件类型及内容去重，不作为标准 PV 或独立访客 UV。
- 文章区间访问仅统计当前已发布文章；相册区间合计保留已下架相册的计数。站点总量还包含独立站点上报，因此不能用文章访问占比解释为阅读转化率。
- 待审核数量和内容状态为当前快照，不受所选时间区间限制；近期内容、草稿、评论和图片按最近更新时间或创建时间展示。
- 资源登记大小来源于有效资源元数据，不是云存储实际占用量，也不是存储额度。直传记录不代表文件完整性已验证。
- 来源渠道、地域、停留时长、实时在线和增长率不在当前首页范围内。

## 加载与交互

概况、趋势、文章排行及相册分别读取后台接口，可独立加载、重试和报错。日期切换时重新读取所选窗口，刷新失败明确提示，不把失败解释为零数据。移动端使用单列布局和分列指标，主要入口保留。

界面只在登录后台后可见；私有文章和待审核评论不进入公开站点。详细字段、列表上限和访问限制见[首页 API](../apis/dashboard.md)。

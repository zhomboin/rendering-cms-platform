# 文章插图

上传图片最大 50MB，超限不发起上传请求。

文章编辑器的“插入图片”支持上传、手动链接、相册和资源选择。图片插入正文打开弹窗时的光标位置；有选中文字时替换该选区，保留前后正文。取消不会改变正文。

## 图库选择

- 相册来源按所选相册加载照片；资源来源展示有效且未删除的 PNG、JPEG、WebP 图片。
- 只展示已有长期公开地址的图片；不使用会过期的下载链接，不创建公开副本，不改变相册状态或资源权限。
- 每次打开读取当前列表，刷新完成前不提供旧候选选择。
- 支持搜索、缩略图放大、前端分页和多选；选中项在切换相册或来源时保留，相同图片地址只插入一次。
- 图片描述来自照片描述或资源文件名。确认后按选择顺序插入，关闭并重新打开时重新选择。
- 图库只读复用原图片地址，不复制文件。上传和手动链接维持各自入口。

## 公开范围

资源选择要求状态为 active、删除时间为空、格式受支持，且公开地址有效；归档、删除、非图片、无公开地址或带临时签名的项目不进入选择列表。普通资源只有临时下载地址时不能从图库插入正文。

相册来源使用后台相册及照片接口；能否在图库使用由图片地址决定，选择图片不会发布或下架相册。

## 界面与验证

使用简洁中文标签；预览和勾选为独立操作。加载、空数据和失败有明确状态，失败可以重试；长名称及窄屏应保持可操作。

本地验证覆盖选择与公开范围、原光标和选区、跨相册及来源多选、去重、搜索分页、预览、异常重试、取消及重新进入，以及上传和手动链接；全量回归由 [GitHub CI](../../.github/workflows/verify.yml) 执行。生产实图和对象存储访问单独验收。

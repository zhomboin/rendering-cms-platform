# 后台界面设计

后台采用浅色拟物主题：冷白蓝紫底、深蓝文字、微浮面板和内凹控件。光影只用于区分界面层次，表格、表单内容和编辑正文保持平整。页面只保留操作所需的中文文案、限制和反馈。

组件级尺寸、样式、交互状态和窄屏规则见项目 skill [soft-skeuo-dashboard](../../.agents/skills/soft-skeuo-dashboard/SKILL.md)。通用颜色由 [主题色板](../../frontend/src/app/theme-colors.ts) 维护；Ant Design 组件变量见 [应用主题](../../frontend/src/app/theme.ts)，局部组件沿用这些颜色和共享光影。

| 范围 | 规则 |
| --- | --- |
| 壳层 | 工作区随浏览器宽度伸缩，只保留小外边距。桌面侧栏 224px，可收起；768–1023px 默认用 68px 图标栏；更窄时通过顶栏打开抽屉。顶栏保留当前模块和账号菜单。 |
| 颜色 | 画布 `#F0F1FA`、面板 `#F8F8FF`、内凹 `#E8EAF5`、主文字 `#25345D`、主操作 `#2456C7`。状态有文字或图标，不依赖颜色。 |
| 控件 | 常规高度 36px，主要触屏操作使用 44px；控件圆角 8px，面板圆角 16px。按下不移动布局；焦点可见，错误紧靠受影响的字段。 |
| 表格 | 微浮容器、平面行、细分隔线和可辨的表头。主列标题可用键盘打开；宽表在容器内部滚动。 |
| 表单与弹层 | 输入、日期和选择控件使用内凹表面。弹窗、抽屉和提示采用同一色板；危险确认标明具体动作。 |
| 仪表盘 | 访问折线和真实文章状态构成优先显示。默认 30 天，可切换 7／30／90 天；环图只展示互斥的现有状态。详见 [首页说明](dashboard.md)。 |
| 媒体 | 上传队列按文件显示真实进度、处理中和最终结果，未知总量不显示虚假百分比。相册和图库缩略图保留放大入口，照片完整 URL 可复制。 |
| 编辑和审核 | 编辑工具条与正文有清楚的层级。图片选择与放大分开，窄屏保留编辑和预览切换。审核状态配文字，常用操作可直接触达。 |

相册基本信息和图片管理保持独立。相册上传列表可清除已结束的记录，离开时取消未完成的浏览器请求；相册封面和图片可用键盘放大，按 Esc 关闭。插图弹窗保留原光标位置，预览和勾选互不影响。

次按钮通过微浮到内凹的变化反馈按压。分段选项和当前导航项有细色标，键盘焦点使用独立描边。内容环图的外缘有高光，色段沿内凹轨道排列。光影方向参考 [Cieden 仪表盘](https://dribbble.com/shots/8806102-Skeuomorphic-Dashboard)，按压状态参考 [Menai Nizar 的按钮对照](https://dribbble.com/shots/23866218-Neumorphism-Button-Design-Initial-and-Active-State)。

在 4K 宽屏上并排更多内容，列表和图库使用可用宽度；单列设置表单、登录和阅读正文限制行长。验证覆盖 320px 手机、横屏、平板、普通桌面、缩放后的 4K 和 3840px 宽屏，以及键盘焦点、长内容和媒体操作。文章插图的公开地址与来源规则见 [文章插图](article-images.md)。

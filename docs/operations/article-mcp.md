# 接入 AI 内容管理客户端

## 本地启动

1. 在 WSL 仓库根目录按[本地开发](development-environment.md#推荐开发启动顺序)准备本地配置、启动依赖并执行全部迁移，包括 `000025_article_delete_request_keys`。
2. 启动 CMS，在浏览器登录管理员账号，打开侧栏 **MCP 管理 → 服务设置**。

   ```bash
   bash scripts/env/start-dev-stack.sh
   ```

3. 填写 CMS API、管理后台和博客的来源（协议、域名和可选端口），开启服务并保存。后台与 API 同源时，后台来源可留空。接入地址由 CMS 自动拼上 `/api/v1/mcp`。修改地址时同步调整实际域名、反向代理和客户端配置。生产使用 HTTPS，开发环境的回环地址支持 HTTP。
4. 核对公开入口。服务开启后无凭据请求应返回 401，关闭后应返回 404。

   ```bash
   export MCP_ORIGIN='<CMS API 来源>'
   curl -i -X POST "$MCP_ORIGIN/api/v1/mcp"
   ```

初次使用时可直接在页面配置。部署变量 `MCP_ORIGIN`、`MCP_ADMIN_ORIGIN`、`MCP_BLOG_ORIGIN` 可提供初始来源；配置完整时初始开启，留空时初始关闭。管理员保存的地址和开关存入 PostgreSQL，对所有实例的后续请求生效。内网或本地博客需要服务端探测时，在部署配置中设置受信任的 `MCP_BLOG_ORIGIN`。后台填写的其他博客地址仅可探测公网。

## 签发和使用连接

1. 在 **AI 连接 → 新建连接** 为每个 AI 客户端单独命名并勾选需要的工具，默认只勾选四项文章草稿权限，相册和照片按需勾选。选择 Bearer 令牌，创建后复制接入地址和只显示一次的令牌。
2. 在 AI 客户端添加 Streamable HTTP 服务，粘贴 URL 和令牌。客户端若要求手工填写请求头，名称为 `Authorization`，值为 `Bearer <连接令牌>`。妥善保存凭据；撤销后重新签发会建立新的文章归属。
3. 让 AI “把这份笔记整理成草稿，返回预览链接”。打开预览核对内容。在 **AI 连接** 点击刷新，可以看到连接权限、最近上报的客户端名称和访问时间。无状态 HTTP 以请求记录反映使用情况。
4. 在对应行点击 **配置权限**，在文章、相册或照片组勾选或取消对应操作，点击 **保存权限**。保存后使用原令牌即可，请客户端刷新工具列表。可以只保留读取或状态查询，也可以全部取消。需要自动发文时勾选 **发布文章**；若需让 AI 重新审稿，同时保留 **读取文章**。**撤销** 会使该连接的凭据永久失效。
5. 打开 **操作记录**，刷新后可查看本人连接的调用时间、工具、结果和成功涉及的文章或相册。结果待确认时先核对稿件状态。记录从启用该能力后的真实调用产生；日志仅保留操作元数据。

## 设置文章封面与首页精选

在已有连接勾选「创建草稿」或「修改草稿」，需要查看当前版本时勾选「读取文章」。例如，让 AI「把这篇草稿的封面设为给定图片地址，加入首页精选，排序设为 10，保留正文」。AI 读取草稿版本后调用 `update_draft`，只提交封面和精选字段；需要公开发文时，按返回的新版本发布。创建草稿时也可一次设置这三项。详细字段见[文章工具](../apis/article-mcp.md#工具)。

## 数据可见范围与工具查询

在 **AI 连接 → 配置权限** 选择「仅本连接创建」或「全部可读内容」并保存。要让 AI 查看已有相册，勾选「列出相册」并选择「全部可读内容」。读取照片还需勾选「查看照片」。私有文章始终受保护。已发布相册追加授权单独设置。已有连接默认保持「仅本连接创建」，范围变更在下一次数据请求生效。

从仓库根目录运行下列命令（Python 3.11+）。命令读取当前环境 Codex 配置里的 `cms-mcp` 地址与令牌环境变量，执行标准 MCP 握手和 `tools/list`，打印这条凭据现在能调用的工具。

```bash
python3 scripts/env/list-mcp-tools.py
```

如果 Codex 配置保存在另一个环境，显式传入管理页显示的接入地址，再按提示输入连接令牌；也可使用 `CMS_MCP_TOKEN` 环境变量。

```bash
python3 scripts/env/list-mcp-tools.py '<CMS 接入地址，含 /api/v1/mcp>'
```

工具列表只列出工具名。数据范围可在连接列表查看，也可用同一连接调用相册列表核对可见数据。命令独立查询服务器；让已打开的 AI 聊天加载新增工具，需要由客户端重新发现工具或重新连接。

## 用 AI 管理相册

1. 在 **MCP 管理 → AI 连接 → 配置权限** 选择工作所需的相册与照片操作。让 AI 建相册并返回 ID，后续会话可用「列出相册」找回。保存后用同一令牌刷新工具列表。
2. 给连接勾选「上传照片」后，可将图片内容交给客户端直接上传。较大文件让客户端先用相册 ID 和请求键获取上传地址，再用同一凭据提交文件。完整参数见 [相册和照片](../apis/article-mcp.md#相册和照片)。
3. 需要整理照片时，勾选「查看照片」及具体写操作。核对照片后可单独授权「发布相册」。整理本连接已发布相册的已有照片时先下架；重新发布后博客按原 slug 展示。
4. 向已有的公开相册添加照片时，在目标连接勾选 **上传照片**，在 **可追加照片的已发布相册** 中选择目标并保存。使用原令牌调用 `upload_album_photo`；先用相册 ID 和请求键获取上传地址，再提交文件，或直接提交小图。收到 `photoId` 后可在相册核对，无需下架。移除目标或取消上传即可收回授权，在途任务提交前会再次检查。
5. 在「操作记录」核对上传结果。文件上传需要与后台相册相同的对象存储配置和公开图片地址。生产验收使用已获准的测试相册。

## OAuth 客户端

部署已有 OAuth 授权服务器时，可以让 AI 客户端完成委托授权。

1. 为 MCP 注册资源标识 `<MCP_ORIGIN>/api/v1/mcp`，在授权服务器登记客户端回调和范围 `articles:draft`、`articles:publish` 和 `albums:manage`。草稿范围是每个连接必需的基础权限。
2. 给 CMS 配置 `MCP_OAUTH_ISSUER` 和 `MCP_OAUTH_PUBLIC_KEY`。后者是至少 2048 位 RSA 验签公钥的 SPKI DER 的单行 Base64，可用 `openssl pkey -pubin -in '<公钥文件>' -outform DER | openssl base64 -A` 生成。签名私钥由授权服务器持有。验签公钥轮换时同步更新 CMS 配置并重启服务。
3. 管理员在「新建连接」选择 OAuth，填写名称以及授权服务器签发的客户端 ID 和主体。客户端连接 MCP URL，按 401 返回的资源元数据发现授权服务器。访问令牌使用 RS256、`typ=at+jwt`，包含 `iss`、目标 `aud`、`exp`、`sub`、`client_id` 和空格分隔的 `scope`。文章发布、相册和照片需要对应令牌范围与连接工具授权同时允许。
4. 用真实客户端核对登录、工具发现、草稿隔离、增减权限和撤销。撤销 CMS 连接立即阻断后续调用；仅在发行方撤销已签发的自包含令牌时，CMS 本地验签以令牌过期时间为界。

## 核验博客搜索

从有权核验该文章的管理员终端运行下面的脚本。它从 CMS 读取已发布版本，用独立 Chromium 查询博客的 `/pagefind/pagefind.js`，逐项比对结果 URL，并把结果和版本送回 CMS。浏览器只接触公开索引，管理员凭据仅发给 CMS。真实结果可供 AI 下一次 `article_status` 查询。

```bash
(cd frontend && npm ci && npx playwright install chromium)
export MCP_ORIGIN='<CMS API 来源>'
read -rsp '管理员访问令牌：' CMS_ADMIN_TOKEN
printf '\n'
CMS_ADMIN_TOKEN="$CMS_ADMIN_TOKEN" node scripts/env/verify-article-index.mjs '<文章 UUID>'
unset CMS_ADMIN_TOKEN
```

当博客重建或更新索引后应再次核验。索引不可读或验证期间文章版本变化时脚本以非零状态退出。页面和静态索引的发布联动按[博客发布对接](rendering-blog-publishing-integration.md)验收。

## 生产接入与回退

1. 按[部署流程](deployment.md#首次部署)核对候选提交与镜像，按[备份流程](backup.md)备份 PostgreSQL 并验证备份。在不入库的生产配置中填写 HTTPS 来源及可选 OAuth 配置。
2. 在获准的发布窗口按部署文档执行 migration、启动后端和前端、更新并校验代理。在后台核对服务设置，获准开启后，确认 `/api/v1/mcp` 未授权返回 401。启用 OAuth 时，`curl -fsS "$MCP_ORIGIN/.well-known/oauth-protected-resource/api/v1/mcp"` 应返回对应资源和发行方。
3. 创建独立草稿连接，完成试写、人工预览、重复请求、私有隔离与撤销。发布和搜索收录用另行授权的公开样稿验收。环境验收登记在[当前任务](../plans/current-tasks.md)。
4. 只需关闭某个客户端时撤销对应连接。需要关闭整个入口时，在「服务设置」关闭并保存。若需回退到仅依赖环境变量的应用镜像，先核对其 MCP 环境变量，防止回退时意外开放入口。回退到不支持逐工具授权的镜像前，先关闭 MCP 入口；恢复连接前核对授权，撤销受限连接以防回退扩大权限。回退指定相册追加功能时保留数据库并回退应用，追加入口恢复为仅允许自建草稿；执行 000024 降级会移除追加授权和跨连接重试记录，已上传的照片保留。单独回退数据范围功能的应用后，读取恢复为仅本连接创建；若执行 000023 降级，范围设置将丢弃，业务内容和工具授权会保留。回退相册功能时优先保留数据库，仅回退应用。执行相册降级迁移会移除相册工具授权、连接绑定和上传请求键，已创建的相册与照片保留。业务文章保留；数据库恢复按[恢复说明](restore.md)单独审批执行。

## 当前能力

| 范围 | 能力与源码验证 |
| --- | --- |
| 文章 | 草稿、发布与下架、私有阅读、修订对比与恢复、英文名和标签整理、正文和图库选封面。公开列表返回轻量数据，详情提供正文，详情、评论和上报使用同一套文章标识解析。见 [文章 API](apis/articles.md) 与 [编辑和插图](guides/article-images.md)。 |
| 正文 | 编辑预览与后台阅读使用与 Rendering 一致的受控 MDX 核心，支持 GFM 表格、安全换行、一至六级标题和唯一目录锚点。两仓均已合入，公开页面及搜索待环境验收。见 [Markdown 规则](guides/markdown.md)。 |
| 登录 | JWT 会话、登录失败锁定、风险触发邮箱验证码、六位验证码自动提交。生产启动拒绝开发管理员初始化和验证码明文日志，显式开启验证码时检查 SMTP 配置。见 [认证 API](apis/auth.md)。 |
| 相册 | 首次发布后固定 slug，照片经过尺寸校验和隐私元数据剥离。相册写入使用事务和相册锁，上传和删除失败可由持久清理队列补偿。PostgreSQL 回归覆盖并发、失败回滚和迁移往返。见 [相册 API](apis/photos.md) 与 [相册数据规则](sql/schema.md#相册规则)。 |
| 首页与统计 | 仪表盘提供 7／30／90 天趋势、图文排行、待办与资源概况。文章、相册与站点按日去重，事件和相应计数原子写入。见 [首页说明](guides/dashboard.md) 与 [统计 API](apis/analytics.md)。 |
| 评论与文件 | 评论默认待审核，后台支持分页与批量审核。文件支持预签名上传下载、搜索筛选和下载审计。见 [评论 API](apis/comments.md) 与 [文件 API](apis/assets.md)。 |
| 后台界面 | 浅色拟物主题、透明工作区、手机至 4K 自适应。相册照片逐文件展示进度、预览、完整链接与排序。见 [前端设计](guides/frontend-design.md)。 |
| AI 写作 | 管理员可在 MCP 菜单配置服务、为每个连接逐项配置文章、相册与照片权限及数据可见范围，查看客户端活动与工具日志。浏览器已在本地验收服务开关、签发、权限变更、撤销、日志和不同屏宽。相册默认关闭授权，支持按连接隔离的相册发布、下架和照片上传、排序、封面、说明与删除。MCP 支持连接隔离的草稿协作、按版本发布、公开页面探测与版本化搜索核验。PostgreSQL 和 SDK 客户端验证草稿、重试、私有隔离、撤销和并发，浏览器使用模拟索引验证命中、未命中与异常。本地验证覆盖跨连接读取、同令牌收窄范围、私有保护与后台配置。管理员可授权向指定已发布相册追加照片；双入口上传、跨连接重试、在途撤权和清理已通过本地验证。命令行可主动查询实时工具列表。生产范围切换见 V12。参见 [MCP 接口](apis/article-mcp.md)。 |
| PostBridge | CMS 已实现连接、来源授权、准备稿、分发及取消、事务发件箱和管理后台。支持图片的 CSDN 目标可保存已发布相册的正文图片。PostgreSQL 和模拟接口验证通过，跨系统、真实 CSDN 和生产验收见 [接入与验收](plans/2026-11-05-postbridge-integration.md)。 |
| 部署 | Docker Compose 两层代理、公开缓存与限流、定时部署、备份失败阻断与按提交标记镜像。数据库回滚脚本在 SQL 错误时停止导入后的发布步骤。见 [部署](operations/deployment.md)、[自动部署](operations/auto-deploy.md) 与 [恢复](operations/restore.md)。 |

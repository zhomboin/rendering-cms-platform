# 浅色拟物后台

把导航、按键和轨道做出同一材质的触感，让文字、数据和操作在浅色界面上清楚可辨。视觉原型为 [Olya Marchak 为 Cieden 设计的 Skeuomorphic Dashboard](https://dribbble.com/shots/8806102-Skeuomorphic-Dashboard)。借鉴冷白蓝紫色、统一光源、微浮面板和内凹控件；页面结构、数据和文案取自实际业务。

## 使用方法

1. 确认本次交付是设计规格、实现还是检视，按用户指定的页面和组件范围处理。读现有主题、组件库、页面流程和项目约束；优先沿用现有组件与行为。
2. 先读 [基础样式](references/foundations.md)，列出当前页面用到的组件，再按下表读相关规格。先匹配规格中的语义和状态，再套尺寸、配色和光影。单页只读取相关规格。
3. 从参考规格中复用变体。新组件先找最接近的现有模式，再明确尺寸、表面、边框、圆角、光影、各交互状态和窄屏行为。保留项目已有且有效的无障碍与操作约定。
4. **设计规格**给出组件、变体及状态的具体数值和布局。**实现**优先映射已有主题与组件变量，剩余视觉细节用局部样式；核对浮层、键盘和异常状态。**检视**报告页面位置、可观察问题和最小修法，只有任务要求时才改代码。

## 判断标准

- 优先保证数据和动作清楚。表格只抬高容器，行不做独立浮卡；同一控件用边界、图标、文字或位置传达状态，阴影只提供质感。
- 色彩和图表服从业务。没有比例数据就不画比例仪表；不增加演示数据、无依据的指标或页面说明。
- 设计时核对适用状态：默认、悬停、焦点、按下或选中、禁用、加载、空、错误和窄屏。只对实际存在的交互应用对应状态。
- 实现后验证真实渲染：键盘可到达主要动作，浮层可退出且焦点合理恢复，中文长内容可读，加载不会让主要操作跳位，错误可恢复，窄屏可操作。核对正常文字及必要控件边界的对比度。
- 在 Rendering CMS 中沿用 React、Ant Design 和现有页面行为。首页继续使用真实访问趋势和 7／30／90 天，文章列表保留筛选与编辑路径，图片管理保留真实逐文件进度和完整地址复制。以同一主题验证首页和高密度文章列表，确认两种页面都适用。

# CMS 组件

先按 [基础样式](foundations.md) 统一主题。CMS 专用组件由通用控件组成；业务现有的权限、状态、数据来源与操作语义优先。

## 上传和文件

- 上传区用内凹底、1px 虚线控件边框、12px 圆角，内距 16–24px；整块支持拖入，保留「选择文件」按钮供键盘和触屏使用。拖入可接收的文件时用选中底和主色边框。仅显示实际限制，例如允许类型和大小。
- 上传队列用平面列表，行高至少 44px；文件名、状态和动作分别对齐。每项有真实百分比和 6px 进度条；100% 但仍等待服务端结果时显示「处理中」。成功显示结果，失败保留文件名和可处理原因；可重试时提供逐项重试。
- 窄屏让进度条和状态换到下一行；文件名可换行，取消和重试能独立触达。网络失败或多个文件部分成功时保留已完成项。
- 文件资源沿用表格或列表规格，类型和大小使用可读文字，主要动作放在末端。下载请求中只锁定对应动作；已过期时允许重新申请，不把临时地址表现为永久公开链接。

## 相册、图库和预览

- 相册卡片用面板底、16px 圆角和 12px 内距；封面建议 4:3，圆角 8px；下方只放标题、必要状态和关键操作。封面可打开预览，卡片主操作另有清楚入口。
- 图库网格桌面卡宽约 144–200px、间距 12px；窄屏优先双列，再按实际宽度缩为单列。缩略图裁切仅用于网格，放大预览显示完整画面。卡片选中用 2px 主色描边和勾选，键盘焦点仍可区分。图片加载保留比例，失败有占位及可用的恢复方式。
- 图片选择弹窗按来源、检索、选择结果组织，选择与预览分开。文章插图只展示符合实际权限和长期公开地址要求的候选，不把预览签名链接当可插入地址。
- 预览层使用深蓝遮罩，图片居中等比缩放；关闭、上一张、下一张按钮保留可见焦点。支持 Esc 关闭、方向键切换，关闭回到触发项。复制按钮高至少 32px；地址允许截断展示，复制必须写入完整原始地址并有结果反馈。

## 编辑、审核和发布

- 文章编辑器：工具栏 40–44px、16px 图标、4–8px 间距，外壳可微浮；编辑和预览面使用面板底，内距 16px、1px 分隔、圆角 12px。格式激活用选中底与按下状态。桌面双栏在正文仍可读时启用；窄屏用页签切换，保留滚动位置和内容。侧栏字段分组，不抢正文视觉重心。
- 文章状态：草稿用普通色，已发布用成功色，归档用普通色并保留名称；私有同时用锁图标和文字。保存中、失败、未保存要区分，失败保留内容。页面只有一个视觉主操作，明确区分保存草稿、发布、归档等行为。
- 评论审核：正文和来源优先，状态使用标签；待审核使用警告色。高频审核动作可见，其余进菜单；批量处理有选中数量和结果反馈。行高随长评论扩展，窄屏依然可阅读正文和处理状态。
- 外部分发：状态、目标、最近更新放在同一行或详情摘要；处理中使用信息色，待确认用警告色，失败用错误色。需人工核对时说明可执行的下一步；分发任务的状态以实际接口为准，不用单纯动画模拟进度。

## 登录和首页

- 登录容器宽约 400–440px、圆角 20px、内距 24–32px，只在外壳微浮。输入控件可用 44px 档；认证错误在对应区域出现。验证码沿用 [表单规格](controls.md)，窄屏校验各格和提交按钮可触达。
- 首页保留真实数据、切换周期和待办去向。访问趋势用折线；Rendering CMS 默认 30 天，可选 7／30／90 天；不新增没有采集依据的 PV、UV、实时值或增长率。多条统计卡使用同一数据口径和颜色规则。

## 实际验证场景

- 首页：三个统计周期切换后，数据、图例和空结果可读；缺少占比数据时不出现装饰性环图。
- 文章列表：长中文标题、排序、筛选、分页、批量操作和表格空状态都使用统一样式；打开编辑再返回可按产品约定继续查找。
- 表单：键盘可以完成输入、选择和提交；错误保留原值；在窄屏和放大视图下可以看到焦点与错误。
- 相册：逐项显示上传失败、重试、处理中、成功；缩略图可放大，预览可退出，完整 URL 可复制。

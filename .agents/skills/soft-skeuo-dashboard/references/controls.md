# 操作与表单

颜色、光影、焦点、间距和窄屏点击区域继承 [基础样式](foundations.md)。本页的边框未单独指定时用 1px 控件边框。

## 按钮与操作组

| 变体 | 默认外观 | 交互 |
| --- | --- | --- |
| 主按钮 | 高 36px、圆角 8px、横向内距 14px、图标距文字 6px；主色实底和白字 | 悬停和按下分别用主色对应值；按下收起投影；加载替换图标或预留图标位，按钮不变宽 |
| 次按钮 | 与主按钮等高；面板底和边框，可加微浮 | 悬停用悬停底，按下用内凹；禁用用无阴影表面 |
| 文字按钮和链接 | 平面，主色文字；正文链接有下划线或其他清楚的非颜色提示 | 悬停强调文字或加浅底；保留焦点。导航用链接，当前页面动作使用按钮 |
| 图标按钮 | 桌面可视区 32×32px、圆角 8px、图标 16px；图标居中 | 悬停和按下加浅底；有可访问名称，必要时配工具提示；窄屏扩大触控区域 |
| 危险按钮 | 普通工具栏优先危险文字；破坏性确认用危险实底和白字 | 用危险悬停／按下色；待确认和提交中均防重复；不把危险动作放成无标签图标 |
| 分裂按钮与紧凑组 | 同高，组外角 8px，内部用 1px 分隔；菜单箭头独立区域 | 每个动作独立可聚焦；窄屏空间不足时保留主动作，低频动作收进菜单 |

## 输入与选择

| 组件 | 样式和尺寸 | 状态与窄屏 |
| --- | --- | --- |
| 输入框／搜索／密码 | 高 36px、内凹底、圆角 8px、左右内距 12px；图标 16px。搜索图标在左，清除和密码显隐在右 | 悬停强化边框，焦点加外框；只读保留文本可复制；禁用去内影。尾部按钮可键盘到达 |
| 数字输入 | 同输入框，数字对齐；桌面步进区在末端，分隔宽约 26px | 触及范围时禁用对应步进；错误显示具体范围；触屏保留可直接输入的方式 |
| 验证码输入 | 单格约 40×44px，间距 8px，居中等宽数字；每格沿用内凹底 | 当前格显示焦点，允许整段粘贴；窄屏可缩至约 34px 并缩小间距 |
| 多行文本 | 同输入框，默认高 96px，内距 12px；计数放底部右侧 | 可输入时支持垂直展开；仅在业务限长时显示计数；报错后保留输入 |
| 单选选择器／自动完成 | 关闭时同输入框；展开层为 12px 圆角微浮面板，选项高至少 36px | 悬停浅底，选中加勾，键盘高亮单独可见；查询加载和无匹配在浮层内。小屏宽度限制在视口内 |
| 多选选择器 | 输入区最小高 36px；已选项用高 22px 的普通标签，间距 4px | 删除标签有名称；宽度不足可折行，或显示余量并让用户展开；不能只截断全部选中值 |
| 日期／时间／区间 | 触发器同输入框；日历网格日期单元约 36×36px；区间浅蓝连带，起止日主色实底；今天使用轮廓 | 禁用日期可辨；保留键盘选择和日期格式提示。窄屏双月变单月，确保可翻月；错误不清空已选值 |
| 级联／树选择 | 同选择器触发器；列表最小行高 36px、树每级缩进 16px，箭头和标签分区 | 层级名称始终可见；支持键盘展开和折叠；窄屏多列级联改为逐层面板，可返回上级 |
| 复选框／单选 | 18px 标记；复选圆角 4px，单选圆形；默认面板底和边框 | 选中实底配勾或圆点，半选配横线；标签可点击，焦点包住可见标记；禁用不靠透明度表达 |
| 开关 | 38×22px 内凹轨道，滑块直径约 16px；关闭浅蓝灰、开启主色 | 位置和颜色同时变化；用固定标签说明设置对象，异步切换失败时恢复并提示 |
| 滑杆 | 6px 内凹轨道、约 18px 滑块；值区间用主色 | 拖动时显示值，键盘步进；需要精确值时配数字输入。触屏扩大触控区域 |
| 穿梭框 | 两列平面列表放在同一浅面板，圆角 12px；选项高 36px，中央放方向按钮 | 同时显示来源与已选数量；无选择时禁用移动；窄屏两列改上下排列，按钮文案说明移动方向 |

## 表单组织

标签与字段相隔 6px，字段之间 16px，字段组之间 24px。默认单列或双列，窄屏回到单列并保留阅读顺序。必填项、错误和帮助文案紧靠关联字段；常驻帮助只解释当前任务需要知道的约束。错误用语义边框和具体文字，不清空内容。长表单的固定操作区用面板底和顶部分隔线，操作区不遮住最后一个字段和焦点。

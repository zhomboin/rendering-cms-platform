# 弹层与反馈

沿用 [基础样式](foundations.md) 的面板、弹层阴影和语义色。必要时用边框、遮罩和空间来区分层级，不能只靠柔影。

## 浮层

| 组件 | 样式与尺寸 | 状态与窄屏 |
| --- | --- | --- |
| 下拉菜单 | 圆角 12px、内距 4–6px、选项高 36px；图标与文字距 8px；危险项单独分组 | 浅底表示悬停、勾号表示选中；菜单支持键盘导航和 Esc；窄屏避开视口边缘 |
| 工具提示 | 深蓝 #25345D 底、白字 12–13px，圆角 6px，内距 6px 8px，宽不超过约 260px | 悬停和焦点都可触发；不在提示里放交互，也不把关键信息只放提示中 |
| 气泡卡片 | 面板底、圆角 12px、内距 12px；标题下留 8px，操作用真实按钮 | 可操作内容支持键盘进入、离开和关闭；空间不足时换方向或用抽屉 |
| 确认气泡 | 小型确认约 240–300px 宽；短动作说明在上，按钮在下 | 适用于邻近且信息简短的动作；不可逆、高影响或需要核对对象时优先弹窗 |
| 弹窗 | 圆角 20px、内距 24px；确认窗约 420px，编辑窗约 640px；底部操作区用分隔线；背景遮罩 #25345D55 | 打开后合理设置焦点，关闭后回到触发处；窄屏边距 16px、正文独立滚动；提交状态不丢失正文 |
| 抽屉 | 桌面常用宽 480px；面板底、标题与固定操作区有分隔线；靠页面的一侧可用 16px 圆角 | 窄屏可铺满，保留可触达的关闭键；表单内容滚动，操作区不遮住最后一个字段 |

危险确认标题或正文要明确对象与后果，确认按钮写实际动作，例如「删除照片」；取消有清楚标签。焦点初始优先放在安全的操作或可读标题；提交中阻止重复确认，失败保留界面并显示原因。

## 反馈和异常

| 组件 | 样式与尺寸 | 使用规则 |
| --- | --- | --- |
| 短消息 | 轻浮面板，圆角 10px、内距 8px 12px，配语义图标 | 用于短时反馈；含重要失败原因或可恢复操作的信息用持续可见的形式 |
| 通知 | 圆角 12px、内距 12–16px，桌面宽约 320px；标题 14px／600 | 可关闭；需要处理时给出直接动作，窄屏限制在视口内，不挡固定操作 |
| 警告条 | 语义浅底和深色文字，圆角 8px、内距 12px，图标 16px | 放到受影响的字段组或面板；错误消息说明下一步，不能只说失败 |
| 加载／骨架 | 局部加载符号 16–20px；骨架高度和实际组件接近，圆角 4–8px | 刷新优先保留结构；必要时给可读状态，减少动态效果时取消闪动；局部提交不要阻塞全页 |
| 空状态 | 平面或面板内居中，内距约 24px；图标可选，标题 16px，动作与标题间隔 12px | 区分无内容、无匹配与无权限。只有可执行时才提供新建、清除筛选或其他动作 |
| 错误／结果页 | 局部错误在原区域，沿用警告条或结果块；全页结果标题 18–24px，突出一个下一步 | 加载失败优先提供重试，权限问题提供可用的返回方式；不把空状态当错误，也不清除已填内容 |

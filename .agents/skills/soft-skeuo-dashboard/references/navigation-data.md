# 导航与数据

沿用 [基础样式](foundations.md)。导航和数据容器可微浮，重复的数据行保持平面；通过字重、分隔线和留白确定阅读顺序。

## 导航

| 组件 | 样式与尺寸 | 交互和窄屏 |
| --- | --- | --- |
| 侧栏 | 展开宽 224–240px，折叠约 64px；面板底，必要时边缘加微浮；导航行高 40px，横向内距 12px，图标 16–18px | 悬停浅底；选中用选中底、深蓝粗体和 2px 短标记，可加轻内凹。折叠时保留可访问名称和提示；窄屏用抽屉 |
| 顶栏／页头／面包屑 | 顶栏高约 56px，用底部分隔线；页面标题与主要操作分列；面包屑 13px、间距 8px，当前项深色 | 只在有层级时显示面包屑，当前项不伪装为链接；窄屏优先保留返回和当前页，操作可换行 |
| 页签 | 平面底，行高 40px，选中用 2px 主色下划线和较重文字 | 键盘焦点与选中可区分；窄屏可横向滚动并保持当前项可见 |
| 分段选择 | 高 36px、圆角 10px，内凹轨道内距 3px；选中块为面板底加轻微浮影 | 选中块有独立边界或图标；各项触控区域稳定；窄屏保留选项文字，必要时换为选择器 |

## 表格

| 区域 | 样式 | 行为 |
| --- | --- | --- |
| 容器与表头 | 16px 面板微浮；表头底 #EEF0FA、高 40px、字号 12–13px、字重 600；单元格横向内距 12px | 排序图标约 14px，当前方向明显，未排序、升序和降序均可区分；如需固定表头，用实底避免穿透 |
| 行与单元格 | 标准行高 44px、紧凑行约 36px；行之间 1px 分隔线；标题左对齐，数字右对齐，状态列使用标签 | 悬停用悬停底；选中用选中底并保留复选标记；可展开行有独立箭头；行内按钮和焦点清楚可见 |
| 文本与操作列 | 主列分配更多空间；长标题最多两行，操作列放在末端，常用动作用文字按钮，其余进入菜单 | 提供读到完整标题的路径，不能只依赖悬停；禁用操作可说明原因。窄屏先保留标题、状态、主操作 |
| 滚动与固定列 | 表格容器允许横滚；固定列用实底和 1px 边界，不覆盖其他焦点 | 优先隐藏或折叠次要列，关键字段不能不可达；按实际任务决定横滚或详情展开 |
| 加载、空与错误 | 初次加载骨架保留表头和列宽；重试和空状态放表体内 | 刷新保留已有行时要能看出正在更新；区分无数据、无匹配和加载失败 |

筛选栏与表格之间留 12–16px；搜索和高频筛选在前，新建或导出在末端。低频筛选可折叠，已生效条件可移除。批量栏高约 44px，显示选中数量和可执行动作；预留位置或覆盖在固定工具区，避免表格跳位。分页按钮桌面最小 32×32px，间距 4px，当前页用选中底、清楚的边界和程序可读的当前状态；窄屏保留当前页和翻页。

## 内容和状态

| 组件 | 样式与尺寸 | 交互和窄屏 |
| --- | --- | --- |
| 列表 | 行高约 44px，横向内距 12px；图标、正文、尾部操作按列对齐 | 交互行才加悬停；长文本和末端按钮允许换行 |
| 卡片 | 16px 圆角、内距 16–20px；只在容器上微浮；标题与正文间距 8–12px | 只有整卡可操作时才整卡高亮；嵌套区域用平面分隔；窄屏按任务顺序堆叠 |
| 详情／描述列表 | 面板内距 16px；字段名用次文字，值用主文字；行距 12px | 窄屏转单列；长 URL 可断行或单独提供完整复制 |
| 树／折叠面板 | 树每级缩进 16px，行高约 36px；展开箭头与标签分区。折叠区行高约 40px，用细线分组 | 展开与选中各有反馈，键盘可访问；窄屏减少装饰缩进，保留可理解的层级 |
| 标签／徽标／头像 | 标签高 22–24px、横向内距 8px、圆角 6px；徽标最小 18px；头像常用 32px | 状态标签用语义文字；可移除标签提供带名称的移除按钮；状态点配可读状态；缺图头像可用首字 |
| 分割线 | 1px 分隔线色，区块间距 16–24px | 仅分隔逻辑相关内容；不替代控件的必要边框 |

## 图表和进度

| 组件 | 样式 | 交互和数据 |
| --- | --- | --- |
| 统计数值 | 数字 28–32px、等宽；指标名 13px，配真实单位或周期 | 比较值仅在有数据与口径时出现；加载、缺数和零值区别展示 |
| 趋势／排名 | 主折线约 2–3px，优先用主色；排名可用条形。网格弱于坐标标签，标签保持可读 | 时间范围在图表附近；关键值能通过键盘提示、图例或表格取得；窄屏减少刻度密度 |
| 分段环图 | 可用 10–12px 环带与 4px 分段间隔；图例显示类别和数值或占比 | 仅用于有明确分母的构成；相似色配文字和顺序，不把悬停作为唯一读数途径 |
| 进度 | 常用 6–8px 内凹轨道，圆角为高度一半；主色填充，错误用错误色 | 保留进度文字；未知总量使用不确定状态，不伪造百分比；完成和处理中区分 |
| 步骤／时间线 | 约 10–16px 节点配连接细线；当前节点用主色和可读状态，完成可加勾 | 窄屏优先竖排；错误步骤标出失败位置和下一步 |

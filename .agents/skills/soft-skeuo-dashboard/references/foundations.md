# 基础样式

下列数值是浅色拟物主题的基准。组件规格出现“面板”“内凹”“微浮”等字样时，使用这里的值；同一项目如需调整品牌色，统一修改主题变量，保持语义和对比度。

## 色板

| 角色 | 值 | 用法 |
| --- | --- | --- |
| 画布 | #F0F1FA | 页面背景 |
| 面板 | #F8F8FF | 内容容器和弹层 |
| 内凹底 | #E8EAF5 | 输入区、分段轨道 |
| 分隔线 | #D6DBED | 非交互分隔、表格横线 |
| 控件边框 | #7B86A3 | 辨认控件所需的 1px 边界；不用于要求有对比的正文 |
| 主文字／次文字 | #25345D／#4B5876 | 标题、正文、表头和辅助文字 |
| 主操作／悬停／按下 | #2456C7／#1E49AD／#183C90 | 实底按钮配 #FFFFFF；主操作色也用于链接 |
| 危险实底／悬停／按下 | #AE2943／#942238／#7C1B30 | 明确的危险确认，配 #FFFFFF |
| 悬停底／选中底 | #E9EFFD／#E0E9FF | 导航、选项和表格交互 |
| 焦点 | #1D4ED8 | 2px 轮廓、偏移 2px |
| 禁用底／禁用文字 | #E8EAF3／#737E99 | 非交互状态；去掉投影，不用作可操作的次要样式 |

语义配色以“文字／底色”表示：成功 #166247／#E5F4ED，警告 #785006／#FFF1D3，错误 #9A263E／#FBE8EE，信息 #204DAB／#E8EFFF，普通 #4B5876／#E8EAF5。状态以文字或图标表达，颜色辅助辨认。

## 字体、尺度和光影

- 沿用项目字体及中文回退。页面标题 24px／650，区块标题 18px／600，小标题 16px／600，正文 14px／400，表头和辅助文字 12–13px，正文行高约 1.5。数字密集区域使用等宽数字。
- 基础间距为 4、8、12、16、24、32px；桌面控件高度为 28、36、44px，默认 36px。窄屏主要操作提供至少 44px 的触控区域；视图可见外形仍可小于触控区域。
- 控件圆角 8px，菜单 12px，面板 16px，弹窗 20px。页面外边距桌面 24–32px、窄屏 16px。参考图的展示画框不用照搬。后台工作区随窗口伸缩，不设统一最大宽度；宽屏增加并排内容，图高和字号维持可读尺度。单列正文、登录和设置表单可限制行长。
- 微浮：左上白色高光 -3px -3px 8px #FFFFFFCC，右下柔影 5px 7px 16px #35467220。
- 内凹：左上内阴影 2px 2px 5px #35467226，右下内高光 -2px -2px 5px #FFFFFFCC。
- 弹层：0 12px 32px #35467226，配 1px 分隔线。压在页面上时用更清晰的遮罩和边界。
- 平面不加阴影。一个组件通常只让其外壳、活动滑块或轨道承担光影，避免行、卡片、字段容器逐层叠影。

## 通用交互

默认以文字、边界、形状和位置表明用途。悬停只给可交互项；键盘焦点用外框，不能被表格滚动容器、圆角裁切或黏性工具栏盖住。按压通过底色与阴影反馈，不推动布局。加载保留宽度并防重复操作。禁用仅用于不可操作项，并保留必要的原因提示。过渡约 140ms，只用于颜色和阴影等反馈；减少动态效果设置生效时取消非必要动画。

普通文字以 4.5:1 为目标；识别必要的控件边界、状态和焦点线索以 3:1 为目标。检查的是渲染后相邻颜色，不能只拿色板值代替。桌面先对齐高密度任务，窄屏按内容优先级折叠；允许数据表在自身容器横滚，页面整体不应被撑宽。
